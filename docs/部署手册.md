# 智能人流统计与考勤系统 · 部署手册

> 适用硬件：树莓派 5（4GB）+ OV5647 CSI 摄像头 + MHS-3.5 英寸 SPI 触摸屏
> 适用系统：Raspberry Pi OS（Debian Trixie，内核 6.18+）/ Python 3.13

## 一、硬件准备

| 序号 | 设备/材料 | 规格 | 数量 |
|:---|:---|:---|:---|
| 1 | 树莓派开发板 | Raspberry Pi 5 4GB | 1 |
| 2 | CSI 摄像头 | OV5647（500 万像素） | 1 |
| 3 | SPI 触摸屏 | MHS-3.5（ILI9486 + XPT2046） | 1 |
| 4 | 电源适配器 | 5V/5A USB-C | 1 |
| 5 | MicroSD 卡 | 32GB 以上（Class 10） | 1 |

## 二、系统安装

1. 使用 Raspberry Pi Imager 烧录 Raspberry Pi OS（64 位，Trixie）。
2. 在 Imager 中预配置 Wi-Fi、SSH、用户名与密码。
3. 首次启动后接入显示器/触摸屏，确认桌面正常。

## 三、环境配置

1. 安装摄像头与触摸屏驱动依赖：

```bash
sudo apt update
sudo apt install -y python3-picamera2 python3-libcamera libcamera-apps
```

2. 创建虚拟环境（复用系统内的 picamera2）：

```bash
cd ~/smart_system
python3 -m venv --system-site-packages venv
source venv/bin/activate
```

3. 安装 Python 依赖：

```bash
pip install flask opencv-python numpy pillow waitress
# TFLite 运行时（Python 3.13 / aarch64 用 ai-edge-litert，即 tflite-runtime 的后继）
pip install ai-edge-litert
```

> 说明：`tflite-runtime` 没有 Python 3.13 的 aarch64 轮子，直接 `pip install tflite-runtime`
> 会报 “No matching distribution found”；改用官方的 `ai-edge-litert` 即可，
> 代码里已做三级回退（ai-edge-litert → tflite_runtime → tensorflow.lite）。

4. 验证摄像头可识别：

```bash
rpicam-hello --list-cameras      # 应列出 ov5647
```

## 四、项目部署

1. 将项目代码复制到 `~/smart_system/`，目录结构：

```
smart_system/
├── flask_app/
│   ├── main.py              # 统一主程序（第七次课）
│   ├── app.py               # Flask 路由 + 视频流 + API
│   ├── camera_manager.py    # 摄像头管理（真实 / 模拟双源）
│   ├── vision_module.py     # 检测 + 质心跟踪 + 计数线判定
│   ├── person_detector.py   # 人体检测器
│   ├── db_helper.py         # SQLite 事件入库与统计
│   ├── config.py            # 配置（分辨率、计数线、匹配距离）
│   ├── models/              # detect.tflite（SSD MobileNet int8）+ labelmap.txt
│   ├── tests/               # test_counter.py 计数逻辑单元测试
│   ├── templates/           # index.html / dashboard.html
│   └── static/              # ECharts 等静态资源
└── detections.db            # SQLite 数据库（自动创建）
```

2. 初始化数据库：

```bash
cd ~/smart_system/flask_app
python db_init.py
```

3. 配置 Systemd 开机自启动：

```bash
sudo cp smart_system.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable smart_system
sudo systemctl start smart_system
```

4. （可选）3.5 英寸屏 Kiosk 自启：

```bash
git clone https://github.com/goodtft/LCD-show.git
cd LCD-show && sudo ./MHS35-show
sudo systemctl enable spi-kiosk.service
```

5. 关键参数（`flask_app/config.py`）：

| 参数 | 默认 | 说明 |
|:---|:---|:---|
| `DETECT_FPS` | 8 | 每秒推理次数，与视频帧率解耦（独立检测线程）；8fps ≈ 单核 81%，发热时可降到 6 |
| `DETECT_THREADS` | 2 | 推理线程数：1 线程 88ms/帧、2 线程 45ms/帧。检测独立成线程后，2 线程实测 CPU 约 60%（单核），比 1 线程+4fps 更划算 |
| `FEED_FPS` | 18 | MJPEG 输出帧率 |
| `COUNT_AXIS` | x | 计数线方向：`x` 竖线（左右过线）、`y` 横线（上下过线） |
| `COUNT_LINE_X` | 320 | 竖线位置（屏幕正中），可在后台“计数线位置”微调 |
| `COUNT_HYSTERESIS` | 28 | 计数带半宽（像素），带内抖动不计数 |
| `COUNT_CONFIRM_FRAMES` | 3 | 越线后需连续确认的帧数 |
| `COUNT_COOLDOWN` | 3.0 | 同一轨迹两次计数的冷却（秒） |
| `API_TOKEN` | smart2026 | 写接口令牌，可用环境变量 `API_TOKEN` 覆盖 |
| `AUTO_START_DETECTION` | True | 开机自动开始统计（kiosk 场景） |

## 六、常见问题

| 问题 | 原因 | 解决方法 |
|:---|:---|:---|
| 服务无法启动 | 路径或依赖错误 | `sudo journalctl -u smart_system -f` 查看日志 |
| 摄像头无法识别 | CSI 排线松动 / 被占用 | 重新插紧排线；确认没有其他程序占用摄像头 |
| 页面无数据 | 未点击"启动" | 调用 `POST /api/start` 或点击界面"▶ 启动" |
| 数据库为空 | 未初始化 / 无事件 | 执行 `python db_init.py` |
| 视频流全黑 | 曝光过低 | 确认 `camera_manager.py` 使用自动曝光 |
| 计数为 0 | 无人跨线 / 计数线位置不当 | 在后台"系统设置"中调整计数线位置 |
| 日志出现“回退背景差分” | 模型或 TFLite 运行时缺失 | `pip install ai-edge-litert`，确认 `models/detect.tflite` 存在 |
| SoC 温度 75 ℃ 以上 | 散热不足 / 环境温度高 | 降 `DETECT_FPS` 到 4、`DETECT_THREADS` 到 1，并加装散热片/风扇 |
| 写接口返回 401 | 缺少 `X-API-Token` | 请求头带令牌，或前端页面内置的令牌不匹配时改 `config.API_TOKEN` |
| 数据库越来越大 | 未清理历史 | `curl -X POST -H "X-API-Token: ..." http://IP:5000/api/prune?days=90` |

## 七、卸载与回滚

```bash
sudo systemctl disable --now smart_system
sudo rm /etc/systemd/system/smart_system.service
sudo systemctl daemon-reload
```
