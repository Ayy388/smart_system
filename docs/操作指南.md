# 智能人流统计与考勤系统 · 用户操作指南

> 系统上电后自动启动，无需手动干预；终端用户面向 3.5 英寸触摸屏，管理员使用 PC 浏览器访问后台。

## 一、系统启动与关机

1. **启动**：接好摄像头与电源，系统自动开机并启动 `smart_system` 服务，约 30 秒后可用。
2. **关机**：在终端执行 `sudo shutdown -h now`，待绿灯熄灭后再断电（避免损坏 SD 卡）。

## 二、访问方式

| 功能 | 地址 | 适用设备 |
|:---|:---|:---|
| 终端控制界面 | `http://<树莓派IP>:5000/` | 3.5 英寸触摸屏 / PC |
| 管理后台 | `http://<树莓派IP>:5000/dashboard` | PC 浏览器 |

> 触摸屏通过 HDMI 自动切换：接 HDMI 时桌面显示在 HDMI，拔掉后自动在 SPI 屏上以 Kiosk 模式全屏显示终端界面。

## 三、终端控制界面（480×320）

### 3.1 查看实时视频

页面中部为摄像头实时画面，画面中：

- **黄色实线** = 计数线（默认是**竖线，位于屏幕正中 x=320**：左侧 OUT 离开区、右侧 IN 进入区；后台可切换成横线）；
- **实线两侧两条黄色虚线之间** = 计数带（±28 px），人在带内来回晃动**不会**被计数；
- **绿色框** = 计数线进入侧（竖线时为右侧）的人员，**橙色框** = 离开侧（竖线时为左侧），
  刚计过数的人会短暂显示为红色粗框，框上标 `P#编号 置信度`，框内绿点为质心；
- 画面左上角显示 `IN:x OUT:y NOW:z`（本次运行累计进入/离开/当前在场）。

### 3.2 启动 / 停止统计

| 按钮 | 作用 |
|:---|:---|
| ▶ 启动 | 开启人体检测与跨线计数（状态栏变绿）；开机默认已启动 |
| ⏸ 停止 | 暂停检测，视频继续显示 |
| 🔄 重置 | 将当前会话的进入/离开计数清零（数据库历史保留） |

> 按钮操作结果以**底部轻提示**显示，不再弹出 `alert` 对话框，避免遮挡 3.5 寸屏画面。

### 3.3 查看状态

底部状态栏实时显示：**视频帧率**、**检测帧率**、累计帧数、**今日进/出**。
画面左上角小字显示当前数据源（摄像头/模拟）、检测方式（SSD检测/背景差分）与在场轨迹数。

### 3.4 进入后台

点击右上角"后台"按钮跳转到管理后台。

## 四、管理后台

### 4.1 统计卡片

顶部四张卡片：**进入总数、离开总数、当前在场、今日进/出**（数据来自 SQLite，
`当前在场 = 累计进入 − 累计离开`）。

### 4.2 图表

- **饼图**：进入 / 离开事件占比；
- **柱状图**：进入 vs 离开数量对比；
- **折线图**：今日 24 小时分时人流（本地时间）。

### 4.3 历史记录

页面中部表格按时间倒序列出最近事件（ID、**本地时间**、类型、来源），
每 5 秒自动刷新，也可点"刷新"；点"导出CSV"下载全部历史。

### 4.4 考勤 / 人流日报

选择日期后查询，显示该日：进入、离开、净流入、首次进入时间、高峰时段，
以及分时统计表（每小时进入/离开/净流入）。

### 4.5 系统设置

### 4.5 系统设置

| 参数 | 说明 | 建议值 |
|:---|:---|:---|
| 计数线方向 | 竖线（左右过线）/ 横线（上下过线） | 竖线（居中） |
| 计数线位置 | 竖线填 x（0~640）、横线填 y（0~480） | 320（竖线居中）/ 220（横线） |
| 匹配距离 | 质心关联的最大像素距离 | 60（人多时调大） |

修改后点击"保存设置"，参数写入 `system_settings` 表，重启后仍生效；
输入非法值（如计数线超出画面）会提示"保存失败"并保持原值。

## 五、日常维护

| 操作 | 命令 |
|:---|:---|
| 查看服务状态 | `sudo systemctl status smart_system` |
| 重启系统服务 | `sudo systemctl restart smart_system` |
| 实时查看日志 | `sudo journalctl -u smart_system -f` |
| 备份数据库 | `cp ~/smart_system/detections.db ~/backup_$(date +%F).db` |

## 六、常见问题

| 现象 | 原因 | 处理 |
|:---|:---|:---|
| 页面打不开 | 树莓派未启动 / 服务停止 | 检查电源与 `systemctl status` |
| 视频全黑 | 摄像头被占用或排线松动 | 停止其他占用程序，重新插线 |
| 数字不变 | 未点击"▶ 启动" | 点击启动按钮 |
| 计数偏多 | 目标在计数带内反复进出 | 调大 `COUNT_HYSTERESIS` 或 `COUNT_COOLDOWN` |
| 计数偏少 | 人员贴边走、遮挡、走得太快 | 调整摄像头角度与计数线位置，必要时提高 `DETECT_FPS` |
| 后台时间不对 | 曾改过系统时区 | 数据按 UTC 存储、本地时间显示，检查 `timedatectl` |
| 点按钮提示"未授权" | 页面令牌与服务端不一致 | 修改 `config.API_TOKEN` 后重启服务并刷新页面 |
| 界面无法全屏 | Kiosk 服务未启用 | `sudo systemctl enable spi-kiosk.service` |
